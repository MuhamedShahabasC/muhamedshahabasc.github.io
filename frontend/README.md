# Muhamed Shahabas C - Portfolio

Personal portfolio website showcasing my work as a Full Stack Developer.

## 🚀 Tech Stack

- **Frontend**: React 18
- **Styling**: CSS3 with CSS Variables
- **Build Tool**: Vite
- **Icons**: Unicons, Boxicons
- **Carousel**: Swiper.js
- **Email**: EmailJS
- **Deployment**: GitHub Pages

## 🛠️ Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/MuhamedShahabasC/muhamedshahabasc.github.io.git
cd muhamedshahabasc.github.io
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file based on `.env.example` and add your EmailJS credentials:
```bash
cp .env.example .env
```

4. Run the development server:
```bash
npm run dev
```

5. Build for production:
```bash
npm run build
```
