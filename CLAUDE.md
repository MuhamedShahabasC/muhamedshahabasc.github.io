# Claude Instructions

Read `AGENTS.md` before making changes. For blog work, also follow
`.skills/write-blog/SKILL.md`.

## Project constraints

- Source lives in `site/`; `dist/` is generated by `scripts/build.sh`.
- Keep the site static: no React, Vite, npm, package manager, build framework, or runtime CDN.
- Use semantic HTML for content, Alpine.js for page state, and Lit only for isolated web components.
- Preserve relative internal URLs, responsive layouts, and the shared light/dark theme contract documented in `AGENTS.md`.
- Every public page must retain its title, description, canonical URL, Open Graph, Twitter, and JSON-LD metadata. Update `site/sitemap.xml` when routes change.

## Before finishing

- Read relevant files before editing and keep changes limited to the request.
- Run `scripts/verify.sh`, then browser-check affected pages on desktop and mobile in light and dark modes.
- Never hand-edit `dist/`, reveal `.env`, or commit credentials.
